<div align="center"><samp><b>Project Overview</b></samp></div>

<samp>Traditional canteen ordering often requires students to queue for billing and then queue again at a food counter. The project documents the problem, a proposed solution and a work plan. This repository currently contains planning documents rather than an implemented application.</samp>
